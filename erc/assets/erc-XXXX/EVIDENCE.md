# Evidence for ERC-XXXX (Decryption Authority Lifecycle)

The ERC cites this file as `[EVIDENCE n]`. Each entry gives the claim, its label and date, how it was obtained, and
where the raw data is in the research repository that accompanies the reference implementation.

**Labels.**
- [M] measured: on the stated network or local machine, on the stated date.
- [V] verified in code.
- [E] estimated, with the method stated.
- [I] inferred.

**What was used.**
- Sepolia transactions were sent only from the authors' own accounts to the authors' own contracts.
- Mainnet data was read with read-only calls; only aggregates are reported.
- The Sepolia measurements of entries 2–6 were made in Phase 1 on the public testnet, with the authors' own accounts.
  Every later measurement ran on local chains, and no request went to a vendor's service.

**The example system** is Zama fhEVM. Its release `v0.13.8` (access-control registry `ACL` v0.4.0) runs on Sepolia and
Ethereum mainnet, checked against Sourcify-verified sources on 2026-10-20 [V]. Code was read at `main` `ed851716c`
and tag `v0.13.8` `fe3ca89b5`.
